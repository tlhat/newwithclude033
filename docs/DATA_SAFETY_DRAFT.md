# مسودة إجابات Data safety (للمراجعة، ما اتقدم شيء)

القواعد: https://support.google.com/googleplay/android-developer/answer/10787469
البيانات اللي بتفضل على الهاتف فقط مش بتتعلن. أي بيانات بتخرج من الهاتف بتتعلن.

| السؤال | الإجابة المقترحة | السبب / ملاحظة |
|---|---|---|
| هل التطبيق يجمع أو يشارك بيانات؟ | **حسب قرار Drive**. بدون النسخة الاحتياطية: لا. | بيانات الطفل محلية. |
| الاسم/البريد (Personal info) | لو الدخول بجوجل موجود: يُجمع (البريد والمعرّف) لغرض App functionality وAccount management، **اختياري**، غير مشارك. | تسجيل الدخول للأهل. |
| ملفات ونسخة احتياطية (App info / Files) | لو النسخة الاحتياطية على Drive موجودة: تُرسل لمساحة Drive الخاصة بالمستخدم نفسه. Google بتعتبر ده نقل لخدمة، فالأسلم نعلنه "مُجمع، غير مشارك"، لغرض App functionality، اختياري. | لازم حسم. |
| الصوت (Audio) | تسجيل صوت الأهل **محلي**، مش مرسل. لا يُعلن كمجمّع. لكن سياسة العائلات بتطلب الإفصاح عن الميكروفون، فاذكره في سياسة الخصوصية وإعلان الأذونات. | محتاج تأكيد من Console. |
| الموقع، جهات الاتصال، الكاميرا، المعرّفات الإعلانية | لا | الأذونات غير موجودة. |
| المدفوعات | لا (تتم عبر Google Play، ولا نخزن شيء) | لو الاشتراك اتفعّل. |
| التشفير أثناء النقل | نعم (HTTPS لجوجل) | فقط لو فيه نقل. |
| طريقة طلب حذف البيانات | حذف التطبيق يمسح المحلي. النسخة على Drive تتحذف من إعدادات Drive، أو بزر داخل التطبيق لو أضفناه. | |
| سياسة الخصوصية | رابط عام (لازم). | مش مستضافة بعد. |
| شارة Families | اختيارية. | |

أسئلة مفتوحة تأثر الإجابات: قرار النسخة الاحتياطية على Drive، وقرار حذف ميزة استيراد الفيديو من الإنترنت، وتفعيل الاشتراك. راجع PLAY_POLICY_NOTES.md قسم 8.
