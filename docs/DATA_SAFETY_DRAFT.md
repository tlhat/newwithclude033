# إجابات Data safety المقترحة (مسودة، ما اتقدم شيء)

قرار المستخدم (26 نوفمبر): النسخة الاحتياطية على Drive تفضل زي ما هي، وتتعلن.
القواعد: https://support.google.com/googleplay/android-developer/answer/10787469

| السؤال | الإجابة | ملاحظة |
|---|---|---|
| هل التطبيق يجمع أو يشارك بيانات المستخدم؟ | **نعم، يجمع** (بسبب الدخول بجوجل والنسخة الاحتياطية). مشاركة مع أطراف ثالثة: **لا**. | |
| Personal info: Email address, User IDs | يُجمع. الغرض: App functionality + Account management. غير مشارك. إجباري لميزات الأهل (الدخول)، الباقي اختياري. | الدخول بجوجل للأهل. |
| Personal info: Name | يُجمع لو الحساب بيبعته (اسم حساب جوجل). نفس الغرض. | تأكد من الكود قبل التقديم. |
| App info / Files: بيانات ملفات الأطفال والتقدم (الاسم الأول، العمر، النتائج) داخل النسخة الاحتياطية | يُجمع (يُرسل لمساحة التطبيق الخاصة في Drive الخاصة بحساب الأهل). الغرض: App functionality. غير مشارك. اختياري (بتفعيل الأهل). | بيانات أطفال خارج الهاتف، لازم نذكرها بصراحة في Families. |
| Audio: تسجيل صوت الأهل | **لا يُجمع**: بيتحفظ على الهاتف فقط ولا يُرسل. لكن اذكر الميكروفون في سياسة الخصوصية وإعلان Families. | |
| Location / Contacts / Camera / Photos / Advertising ID / Financial info | لا | الأذونات غير موجودة. الاشتراك لو اتفعّل يتم عبر Google Play. |
| هل البيانات مشفرة أثناء النقل؟ | نعم (HTTPS مع Google) | |
| هل يمكن للمستخدم طلب حذف بياناته؟ | نعم: حذف التطبيق للمحلي، وإعدادات Google Drive > إدارة بيانات التطبيقات للنسخة الاحتياطية، أو مراسلة tlhatmaher1893@gmail.com. | رابط الحذف اختياري لكن مفيد. |
| رابط سياسة الخصوصية | رابط عام (راجع PRIVACY_POLICY_DRAFT.md وprivacy_policy.html) | لازم يكون مفعل قبل الإرسال. |
| Families (الجمهور المستهدف أطفال) | نعم. لازم تتأكد من Play Console إن خدمات Google (الدخول وDrive) مقبولة لتطبيق أطفال. | راجع PLAY_POLICY_NOTES.md. |

مطابقة الإعلان للكود (مهم): الإعلان لازم يطابق السلوك الفعلي. لو الدخول بجوجل أو Drive اتشال في أي إصدار، عدّل الإجابات.
